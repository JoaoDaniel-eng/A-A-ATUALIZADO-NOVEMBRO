# Identidade visual — Açaí da Roça

Design read: loja de açaí demonstrativa, para clientes em celular; linguagem editorial gastronômica tropical; redesign greenfield. Variação visual 6/10, movimento 3/10, densidade 4/10, dependência de imagem 8/10, fidelidade à identidade descrita 7/10.

As escolhas aprovadas usam creme quente para acolhimento, roxo-açaí para assinatura, verde folha para ações positivas e lavanda como suporte; DM Sans para corpo e Playfair Display para títulos; espaçamento baseado em múltiplos de 4/8 px; cantos de 10–18 px e selo circular; sombras discretas para camadas; animações de 160–220 ms, respeitando `prefers-reduced-motion`.

A marca recebida foi nomeada no briefing como Açaí da Roça 2.0, sem logotipo oficial fornecido. Para esta interface foi desenhado um wordmark tipográfico acompanhado de ícone botânico como representação provisória, não como ativo oficial da empresa.

Imagem em `public/assets/acai-bowl.jpg`: resultado de busca visual salvo localmente para compor destaque e cards; resultado intitulado “How To Make A Delicious Acai Bowl”. Usar apenas como imagem ilustrativa demonstrativa, substituindo por fotografia própria/licenciada da loja antes de publicação comercial. Catálogo, preços, disponibilidade, avaliações, entrega, cupom e pagamento nesta experiência também são demonstrações.
